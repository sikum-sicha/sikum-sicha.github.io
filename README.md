# סיכום שיחה

אתר קטן שמתמלל ומסכם הקלטות של שיחות טלפון בעברית, ישירות מהטלפון.

- משתפים לאתר הקלטה (או בוחרים אותה), ומקבלים תוך דקה תמלול מלא וסיכום מסודר: עיקרי הדברים, החלטות, משימות והצעד הבא.
- את הסיכום אפשר לשלוח בוואטסאפ או במייל, להעתיק, או לשמור את התמלול כקובץ.
- אין שרת: ההקלטה נשלחת מהדפדפן ישירות ל-Gemini API של Google, עם מפתח אישי וחינמי של המשתמש.
- המפתח, הסיכומים והתמלולים נשמרים רק במכשיר (IndexedDB).
- אפשר להתקין את האתר כאפליקציה (PWA). אחרי ההתקנה הוא מופיע בתפריט השיתוף של אנדרואיד.
- סיכום אוטומטי אחרי כל שיחה: בעזרת MacroDroid (חינם). ההוראות נמצאות באתר, במסך "הפעלה אוטומטית".

## פרטיות

במסלול החינמי של Gemini, Google רשאית להשתמש בתוכן שנשלח כדי לשפר את המוצרים שלה. מי שרוצה למנוע את זה יכול להפעיל חיוב (Billing) בחשבון Google AI Studio שלו.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `index.html` | המסכים והעיצוב |
| `app.js` | כל הלוגיקה: קריאה ל-Gemini, סיכום, היסטוריה, שיתוף |
| `store.js` | אחסון מקומי (IndexedDB) |
| `sw.js` | Service Worker: עבודה בלי רשת וקבלת קבצים מתפריט השיתוף |
| `manifest.webmanifest` | הגדרות ההתקנה כאפליקציה ותפריט השיתוף |
| `macro/` | קובץ מאקרו ל-MacroDroid |
